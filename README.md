 # Two Types of Export/Import

 - Default Export/Import

 Eg: export default <name of component or variable>
     import Component from "path";

Note: We cannot use nore than one time default export/import in one file.
 
 - Named Export/Import

    export const name = "";
    import {name} from ../utils;
